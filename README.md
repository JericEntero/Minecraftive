## Minecraftive — Interactive Minecraft Fan Hub

A fan-made interactive Minecraft website built with Bootstrap 5, vanilla JavaScript, and PHP.

## Live Site
(SOON)

## Features
- TNT intro animation with sound effect
- Interactive mob, biome, seed and creator cards
- Carousel modal with autoplay and keyboard navigation
- Falling rain cards in hero section
- Mob sound effects on hover and click
- Contact form with PHP backend validation
- Community section with fan creator videos
- Fully responsive on mobile and desktop

## How to Run PHP Locally
1. Download and install XAMPP from https://www.apachefriends.org
2. Copy the project folder into C:/xampp/htdocs/minecraftive/
3. Open XAMPP Control Panel and start Apache
4. Visit http://localhost/minecraftive/
5. Click Contact in the navbar
6. Click Open Full Contact Form
7. Fill in all fields and click Send Message
8. You will be redirected to contact.php confirmation page
